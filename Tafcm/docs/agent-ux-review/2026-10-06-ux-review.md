## UX Findings

### F-2026-10-06-01（核实）冷启动落在「文件」Tab，该页无新建/搜索/导入入口
- **状态**：已建 Issue 覆盖 → 引用 **#338**
- **证据**：`app_router.dart` StatefulShellRoute 仅 /home + /files 两分支；`file_manager_screen.dart:27-28` AppBar 仅 title '文件'，无任何动作入口；`document_list_screen.dart:21` 同理。首页（home_screen.dart:78）有搜索/新建，但冷启动恢复分支 `last_shell_branch_index` 可能落在 /files。
- **影响**：P2。用户冷启动若落在文件列表，第一屏没有任何"开始创作"入口，需手动切到首页 Tab。
- **建议**：不新建 Issue（#338 已存在）。修复方向：文件 Tab 补新建/导入入口，或冷启动默认落 /home。

### F-2026-10-06-02（核实）编辑器保存状态反馈弱：AppBar 仅一个「•」圆点
- **状态**：已建 Issue 覆盖 → 引用 **#340**
- **证据**：`editor_app_bar.dart:105-111` isModified 时在标题后追加 `Text('•')`，无文字、无 tooltip；`editor_status_bar.dart` 无保存状态项（只显示 块数/字数/可撤销/可重做/字号）。自动保存场景下用户无法得知"已保存 / 保存失败"。
- **影响**：P2。数据丢失风险的感知盲区（保存失败无感知）。
- **建议**：不新建 Issue（#340 已存在）。修复方向：'•' 加 tooltip + 保存成功瞬时 SnackBar。

### F-2026-10-06-05（新观察）导出完成无正向反馈（分享面板被关闭时）
- **状态**：OBSERVED（Hypothesis，不建 Issue）
- **证据**：`editor_export_actions.dart:114-132` 写盘成功即视为完成，随后 `unawaited(Share.shareXFiles(...))` 弹分享面板；若用户直接关闭分享面板，无任何"导出成功"提示。进度状态机会回 Idle（`runWithGuard` finally）。
- **影响**：P3。导出大文档耗时后，用户可能不确定文件是否已生成（文件在临时目录，部分用户不知道去哪找）。
- **置信度**：中（导出完成在多数场景以分享面板形式可见；仅关闭面板场景无反馈）。
- **建议**：不建 Issue。后续可在导出 Completed 状态补一条"已导出到临时文件"的 SnackBar。
