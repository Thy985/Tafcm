# 手机上的 Typora 来了：这个开源写作工具，让 Markdown 所见即所得

如果你在手机上写 Markdown，大概率经历过这些尴尬：

- 编辑器和预览分两个界面，改一行要切来切去
- 公式一多就乱码，写论文 / 记笔记体验劝退
- 下载的 `.md` 文件打不开，还得先导入"专属格式"

今天介绍一个开源项目：**Tafcm** —— 移动端 Typora 类排版写作工具，所见即所得（WYSIWYG），以公式、图表、学术写作为特色。

## 一句话定位

> 不是"带预览的 Markdown 编辑器"，而是**所见即所得的排版写作工具**——你在手机上看到什么，就是最终的样子。

## 手机上的 WYSIWYG

Tafcm 的核心是**块级所见即所得编辑**：标题、段落、列表、公式、代码块、表格、引用、图表……直接在编辑界面渲染成型，没有"编辑 / 预览"模式切换，所见即所得。

## 公式与图表：为学术写作而生

- **公式**：LaTeX 语法，行内公式（$E=mc^2$）与块级公式在编辑器中**直接渲染成排版效果**，无需切换到预览
- **图表**：Mermaid 流程图，写一句 `graph LR; A-->B` 就是一张可交互的图
- **表格 / 代码块**：标准 Markdown 表格 + 代码语法高亮，编辑即所见

## 任意 .md 即开即看

不需要导入 Vault，不需要专属格式——**任何来源的 Markdown 文件，打开就能看、能改**。手机上收到的 .md 文档，直接交给 Tafcm，像看 PDF 一样自然。

## 其他亮点

- **离线可用**：100% 本地渲染，无云端依赖，笔记永远属于自己
- **三套主题**：明亮 / 暗色 / 护眼，一键切换
- **轻量便携**：Android 8.0+，安装即用
