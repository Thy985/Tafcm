# agent-investigations — 复杂 Issue 深度调查

> **命名**：`issue-<NNN>-<slug>.md`（如 `issue-123-export-pdf-hang.md`）。
> **规范**：见 `.agent/tafcm-maintainer/SCHEMA.md` §4。
> **原则**：未定位根因的调查也保留（记录已排除的假设，避免后人重复调查）。
