# ADR-0010：编号跳号说明（SKIPPED）

> **状态**：Closed（编号保留位）
> **生效日期**：2026-08-01
> **起草人**：AI Agent（随 ADR-0021 起草时补齐编号纪律）
> **关联决策**：[ADR-0021 Repository Integrity Strategy](./0021-repository-integrity-strategy.md) §D4.2 单一真相源与编号纪律

---

## 背景

`docs/ADR/` 现有编号 0001-0009、0011-0020，**跳过 0010**。
此跳号未在任何历史 ADR 中记录说明，违反 [AGENTS.md §7](../../architecture/ARCHITECTURE.md) 「NNNN 从 0001 递增，不复用」的隐含语义（递增亦不应跳号）。

跳号最可能来源（推测，待 Owner 核实）：
- Phase 2 起草时把"某个被否决的方案"草稿编号设为 0010，后整段废弃但未留 ADR
- 编号被作者手误占位（如想写"Phase 1.0 → 0010"作为里程碑 ADR，最终未落地）
- 工具/脚本辅助编号时跳了一位

## 决策

**0010 编号位永久保留为 SKIPPED**，不再占用。
任何后续 ADR 不得使用 0010 编号。

后续所有 ADR 必须遵循：
1. 编号严格递增。
2. 跳号需在跳号位创建 `NNNN-SKIPPED.md` 说明跳号原因。
3. AGENTS.md §7 增加对应条款（见 ADR-0021 §D4.2）。

## 后果

- 编号连续性恢复（0001-0020 视作 21 份 ADR，其中 1 份 SKIPPED 占位）
- 不影响现有 ADR 之间的相互引用
- 为未来类似事件建立先例

- [ ] Owner 确认 0010 跳号的真实历史原因（待补）
