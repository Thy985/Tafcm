# Decision Patterns（跨 ADR 决策模式）

> 从 30+ ADR + Phase 历史中跨文档寻找重复出现的决策模式。
> 判断标准：同一模式出现在 ≥2 个独立 ADR / 阶段，且背后有可指认的底层原则。

---

## Pattern DP-01 · Evidence Before Claim（证据优先于声明）

- **Appears In**: ADR-0030（不变量 3：Evidence > Agent 自述）、ADR-0024（Never trust candidate_causes）、ADR-0021（Observed Reality > Agent Inference）、VERIFICATION-POLICY、FULL-CAPABILITY-REAUDIT、Phase 3.11 全部 run
- **Pattern**: 任何"完成/修复/正确"的主张，都必须用可复现证据支撑（before=failed → after=passed → regression=passed 的实证链），而不是声明、推断或测试全绿的局部信号。
- **Why it appears**: 项目大量由 AI Agent 执行，"声明不可信"是常态假设；把证据要求制度化是让 Agent 输出可信的唯一方式。
- **Underlying Principle**: 可信度来自可审计的证明过程，而非宣称者身份。
- **Confidence**: **High**（6+ 独立出现点，且被 ADR 显式固化为不变量）

## Pattern DP-02 · Permission Boundary（权限边界显式化）

- **Appears In**: ADR-0025（analyze job 零写权限）、AI_POLICY（权限矩阵）、AGENTS.md §6.4（Human-Owner 文件）、ADR-0021（Git 权限模型）、FFX（verify/diagnose 只读、repair-verify 不修代码）
- **Pattern**: 每个 Agent/工具操作都显式声明读写边界；不可逆/影响架构的操作划归 Human；AI 段即使被攻破也无写令牌可借。
- **Why it appears**: 公开仓库 + AI 注入风险下，"权限最小化 + 物理隔离"是安全底线。
- **Underlying Principle**: 权力的授予应遵循最小必要 + 可逆性判断；信任域必须与执行域分离。
- **Confidence**: **High**（5+ 独立实现，job 级 permissions 物理强制）

## Pattern DP-03 · Single Source of Truth（单一真相源）

- **Appears In**: ADR-0003（.md 唯一真相源，三层模型）、ADR-0030（contracts/*.json 机器真相源，Feature Matrix 为派生投影）、ADR-0023（Canonical AST Fingerprint）、FFX（contract-sync 防漂移）
- **Pattern**: 每个事实域（文档内容、功能完成度、渲染指纹）都定义唯一权威源，其他一切为派生；派生与权威之间用同步/校验机制防漂移。
- **Why it appears**: 多源并存（三套存储、静态表 vs 代码、人工 vs 机器）都被真实事故证明是灾难（数据丢失 / verify 误报 / 语义偷换）。
- **Underlying Principle**: 认知成本与数据一致性风险随"真相源数量"线性增长；权威唯一是降低不确定性的根措施。
- **Confidence**: **High**（3+ 独立域复用同一模式）

## Pattern DP-04 · Contract First（契约先行）

- **Appears In**: ADR-0025 D2（context.md 输入契约强制 schema）、ADR-0030（contracts/*.json + 能力契约）、issue-triage（findings.json schema）、contract-sync、test 的 fixture 驱动
- **Pattern**: 跨边界（Agent↔系统、工具↔系统、脚本↔脚本）的数据交换先定义机器可校验的契约 schema；schema 变更是契约变更，走 ADR；实现不得静默改 schema。
- **Why it appears**: LLM 输出不可控，必须先约束其输入/输出形状；自由 schema = GIGO + 注入面。
- **Underlying Principle**: 不可控方的输出必须先被确定性契约收窄，才能安全消费。
- **Confidence**: **High**

## Pattern DP-05 · State Explicitization（状态显式化）

- **Appears In**: ADR-0008/0012（Live/Committed 双态）、ADR-0024（Failure Identity 聚合去重）、Failure Identity 四层（baseline failure set + fingerprint）、ADR-0023（trace_id/span_id 关联）
- **Pattern**: 隐式状态（脏标记、失败、回放、诊断）被显式建模为可识别/可寻址/可聚合的实体（双态对象、failure id、trace id、fingerprint）。
- **Why it appears**: 隐式状态无法被测试、无法被 Agent 消费、无法去重——只有显式化后才能计算。
- **Underlying Principle**: 状态只有被命名和结构化为可寻址实体，才能被自动化处理。
- **Confidence**: **High**（4+ 独立域）

## Pattern DP-06 · Runtime / UI 解耦（渲染与行为分离）

- **Appears In**: ADR-0019（渲染组件不裁决行为，BlockBehaviorResolver 集中）、FFX（Orchestrator 能力无关 + Adapter 注册表）、ADR-0022（Renderer 失败策略独立）、六层架构（core 不反向 import）
- **Pattern**: 渲染/执行层与行为/决策层分离；新增能力通过适配器/扩展点接入，核心零改动（杜绝巨型 if/else）。
- **Why it appears**: 渲染演进速度 ≠ 行为演进速度；耦合导致"改一个渲染必须动全栈"。
- **Underlying Principle**: 变化的维度应隔离到独立边界，通过稳定接口连接。
- **Confidence**: **High**

## Pattern DP-07 · Deterministic + AI 分离（AI 判断，系统执行）

- **Appears In**: ADR-0025（三段式：确定性提取→AI 分析→确定性执行）、FFX（Agent-Native Verification Harness，能力无关的确定性编排）、issue-triage（去重 fingerprint 由确定性脚本计算，而非 AI 语义 kebab）
- **Pattern**: 任何"AI 参与"的流程都拆成：确定性前置（规范化输入）→ AI 只读分析（出建议/结构化结果）→ 确定性后置（白名单校验 + 落地副作用）。
- **Why it appears**: AI 的创造性用在"判断"，系统的可靠性靠"确定性"，两者不可混。
- **Underlying Principle**: 让 LLM 做它擅长的判断，让确定性代码做它擅长的校验与执行；AI 的任何输出都只是"建议"。
- **Confidence**: **High**（此模式是 Tafcm Agent 工程的核心）

## Pattern DP-08 · 环境与产品失败分类（错误分类决定诊断方向）

- **Appears In**: FFX 五级退出码（0/1/2/3/127，ENV_MISSING≠FAIL）、Evidence Strength（模拟器≠真机）、INCONCLUSIVE 覆盖 replay 无果/真机缺失/视觉未判定
- **Pattern**: 验证系统的失败/证据分类必须显式区分"环境缺失 / 产品缺陷 / 证据不足"，并物理编码（退出码/枚举）。
- **Why it appears**: 分类错则 Agent 归因错（"wpscli 没装"被报成"Word Export broken"）。
- **Underlying Principle**: 诊断系统的错误分类是归因的第一道闸门；分类粒度决定诊断质量。
- **Confidence**: **High**

## Pattern DP-09 · 容量/时间预算必须整体建模（单条×规模）

- **Appears In**: CRITICAL-REVIEW §5.3（30s×100/4 导出必然失败）、E2E 全轮 18min 分段、Formula 并发上限 4
- **Pattern**: 批处理/导出/验证的预算按"单条耗时 × 数量 / 并发"整体建模，而不是只看单条；发现乘积超预算立即重设计。
- **Why it appears**: 单条看似可接受，乘积后不可接受——线性思维漏掉规模项。
- **Underlying Principle**: 性能与超时的判断必须以规模为变量。
- **Confidence**: **Medium**（证据充分但"模式化"程度低于前者）
